# 장르 레퍼런스 정리 (2002~2008 여객선형 커뮤니티 게임)

출처: 사용자가 공유한 회고 블로그 글(2024-02-08, 네이버 `ssudolss`). 스크린샷 설명과 본인 기억을 적은 글이라 **수치는 부정확할 수 있다**(글쓴이도 사료 가격을 "10루피였나 20루피였나"로 적음).

> **이 문서의 쓰임**: 시스템·동선·분위기를 이해하기 위한 기록이다. 원본의 명칭·로고·캐릭터·에셋·맵 이름·음악은 가져오지 않는다(`LEGAL.md`). 여기 적힌 것은 "장르가 무엇을 제공했는가"이고, 우리는 그 경험을 우리 이름·우리 팔레트·우리 비율로 다시 만든다.

## 1. 공간 구조 — 움직이는 여객선
- **선실(개인 방)**: 유저마다 배당된 방. 꾸미기의 중심.
- **문(도어)**: 선실에 달린 문을 통해 **남의 선실로 이동**. "어디로든 문" 같은 개념 — 방 목록이 아니라 *공간 안의 오브젝트*가 이동 수단이었다는 점이 중요.
- **엘리베이터**: 층(구역) 간 이동 통로. 지나가다 다른 시설을 보게 되는 동선.
- **공용 시설들**: 댄스홀(핫플), 전망대/스카이라운지, 갤러리, 옷 가게, 미용실, 룸서비스·오락기가 있는 로비.

## 2. 벽 = 방명록
- 캐시를 많이 쓴 유저의 **선실 벽이 포스트잇으로 도배**돼 있었다. 벽에 다닥다닥 붙은 종이 딱지.
- 즉 포스트잇은 장식이 아니라 **사회적 지표**였다. 많이 붙어 있을수록 인기 있는 방.
- → 우리 구현: 이미 있음(벽 슬롯 그리드 + 포스트잇). **벽 슬롯을 더 촘촘하게** 만들면 "도배" 느낌이 산다.

## 3. 채팅 연출 — 하늘로 떠오름
- 하단 채팅창이 아니라, **친 말이 위로 붕붕 떠올랐다**.
- 이 장르의 가장 눈에 띄는 시각적 서명. 여러 명이 동시에 떠들면 화면 위쪽이 말풍선으로 가득 찬다.
- → 우리 구현: 지금은 고정 말풍선. **떠오르며 서서히 사라지는 연출로 바꿀 것.**

## 4. 경제 — 루피
- 화폐 단위가 **루피**. (우리 프로젝트도 이미 루피 사용 중)
- **복권**: 한 장 10루피, 1등 1000루피. 야금야금 사 모으는 재미. 당첨은 잘 안 됨.
- **옷 가게**: 가격이 비싸 대부분 구경만 함. 고인물은 늘 **머리에 뭔가를 쓰고** 있었다(모자 = 지위 표시).
- **애완동물**: 분양가가 비쌌고 **사료를 따로 사야 했다**(10~20루피 추정). 유지비가 있는 아이템.
- → 시사점: 돈 쓸 곳(옷·펫·복권)과 벌 곳(복권 당첨·미니게임)이 짝을 이뤄야 경제가 돈다. 지금 우리는 **벌 곳이 없다**(시작 500루피뿐).

## 5. 상호작용 오브젝트
- **미용실**: 침대 오브젝트를 클릭하면 NPC가 머리를 감겨 주고, **캐릭터 머리에 거품이 뽀글뽀글** 생김. 염색 코너.
- **콜라**: 댄스홀·전망대에서 **무제한으로 콜라를 뽑아** 마실 수 있었다. 한 손에 콜라 들고 춤추는 캐릭터가 흔한 풍경.
- → 시사점: 오브젝트 클릭 → 짧은 연출 → 손에 뭔가 들림(핸드헬드 아이템) 이 루프가 분위기를 만든다. 우리 FSM + emote 로 이미 표현 가능.

## 6. 감정표현 문화
- 모션 종류가 적어서, **자리 비울 때 일단 춤 모션을 켜 두는 게 암묵적 룰**이었다. 가만 서 있으면 밋밋하니까.
- → 시사점: 기본 대기 모션이 밋밋하면 안 된다. 춤이 "자리 비움" 신호로 쓰인다는 게 재미있다.

## 7. 관계 시스템
- **짝짓기 기능**("사랑의 작대기") — 나중에 업데이트로 추가. 여초 게임이라 남캐로 가면 매칭 확률이 높았다.
- **결혼 / 이혼** 시스템. 글쓴이는 3번 결혼, 3번 이혼.
- → 우리 로드맵의 커플 룸·결혼과 일치. 짝짓기 이벤트가 결혼의 앞단.

## 9. 같은 계열: 퍼피레드 (2003-11 ~ 2016-08-19, 트라이디커뮤니케이션즈)

사용자가 "퍼피레드나 팝플처럼" 이라고 방향을 지정. 위키백과·나무위키 요약 기준으로 확인한 것:

- **3D 아바타 커뮤니티.** 주요 콘텐츠가 아바타 꾸미기, **미니공원** 꾸미기, **펫과 식물 키우기**, 채팅.
- 개인 공간의 인터페이스가 **싸이월드 미니홈피와 비슷**했다. 내 공간을 아이템으로 꾸미고 아바타가 그 안을 돌아다닌다.
- 다른 유저가 **찾아와 채팅**, **방명록**, **친구 추가**, **배경음악 설정**.
- 부가로 롤플레잉, 요리, 아기 키우기, 변신 아이템.
- 당시 국내 온라인 게임 중 **집 꾸미기 수준이 높았다**는 평. 2016년 종료 후 모바일 후속작(퍼피레드M)이 나옴.

### 팝플과 겹치는 것 = 이 장르의 뼈대
개인 공간 꾸미기 · 남의 공간 방문 · 방명록 · 아바타 꾸미기 · 펫 · 채팅 · 꾸미기 아이템 경제.
**둘 다 웹에서 로그인해 브라우저로 들어가는 방식**이었다 → 우리가 만드는 웹 로그인 + 입장권 흐름이 이 장르의 정석.

### 퍼피레드에서 새로 가져올 것
| 요소 | 지금 우리 | 메모 |
|---|---|---|
| 미니공원(실외 개인 공간) | 실내 방만 | 방 템플릿 하나 더 추가하면 됨(바닥 스타일·벽 없음) |
| 식물 키우기 | 화분(정적) | **시간이 지나며 자라는** 가구 = FSM + 타이머로 이미 가능 |
| 펫 | 없음 | 팝플 쪽은 사료를 따로 사야 했다 → 유지비 있는 동반자 |
| 배경음악 | 없음 | 방마다 BGM 고르기. 저작권 없는 음원 필요 |
| 친구 추가 | 없음 | 친구 목록에서 바로 그 사람 방으로 |
| 방명록 | 포스트잇 ✅ | 이미 있음 |

## 10. 설계 원칙으로 뽑은 것
1. **이동은 공간 안에서** — 메뉴보다 문·엘리베이터 같은 오브젝트가 낫다.
2. **벽이 사회적 공간** — 남이 내 방에 남긴 흔적이 쌓이는 게 이 장르의 핵심.
3. **채팅은 연출** — 글자가 떠오르는 것만으로 공간이 살아 있다고 느껴진다.
4. **돈은 벌 곳과 쓸 곳이 짝을 이뤄야** — 복권·미니게임이 먼저, 그다음 비싼 옷·펫.
5. **가만히 있어도 움직여 보이게** — 대기 모션이 분위기의 절반.
