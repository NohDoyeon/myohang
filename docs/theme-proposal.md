# 주제 변경안: 사람 → 고양이, 여객선 → 항구 마을

사용자 제안(2026-09-17): "팝플은 사람이었는데, 고양이라든가 새로운 주제로 바꿔서 관리할까?"

## 왜 지금인가
**아직 실제 아트가 하나도 없다.** 아바타는 `AvatarView._Draw` 의 코드 그림이고, 외모는 `figure` 문자열(팔레트 인덱스)일 뿐이다.
아틀라스가 생긴 뒤에 바꾸면 스프라이트를 전부 다시 그려야 한다. 지금은 코드 150줄 수준.

## 왜 고양이인가
1. **원본과 거리.** 아이소 방 + 사람 아바타는 이 장르 원본들과 실루엣이 겹친다. 고양이는 시스템을 그대로 두고 인상만 바꾼다. 공개 이름 문제도 함께 풀린다.
2. **작은 크기에서 읽힌다.** 30px 사람 얼굴은 비율이 조금만 틀어져도 어색하다. 같은 크기의 고양이는 **귀와 꼬리**만으로 즉시 고양이로 읽힌다.
3. **코드명이 이미 Harbor(항구).** 고양이 + 항구 + 생선 → 로드맵의 **낚시 미니게임**이 억지 기능이 아니라 세계의 중심이 된다.

## 원칙: 두 발로 다니는 고양이
네 발로 바꾸면 **앉기(seat FSM)·옷·모자·춤 동작이 전부 깨진다.** 지금 있는 시스템을 하나도 버리지 않으려면 이족보행이어야 한다.
바뀌는 것은 실루엣뿐: 둥근 머리 + 삼각 귀 2개 + 주둥이/코 + 꼬리 + 발.

## 바꿀 것

### 아바타 (`AvatarView._Draw`)
| 지금 | 바꿔서 |
|---|---|
| 둥근 머리 + 머리카락 반원 | 둥근 머리 + **삼각 귀**(털색), 안쪽 분홍 |
| 눈 2개(방향별) | 눈 + **주둥이·코·수염**. 뒷모습은 뒤통수와 귀만 |
| 없음 | **꼬리** — 대기 중 살랑, 걷기/춤에 맞춰 크게 흔들림 (움직임이 생겨 "가만 서 있어도 살아 있게") |
| 다리 2개 | 그대로(이족) + 발 끝 살짝 둥글게 |

### 외모 파츠 (`Figure`) — 코드는 그대로, 뜻만 바꿈
| 파츠 | 지금 뜻 | 바꿔서 |
|---|---|---|
| `hd` | 피부색 | **털색** (SkinTones → FurColors) |
| `hr` | 머리 모양·머리색 | **무늬**(민무늬/턱시도/얼룩/젖소) + 무늬색 |
| `ch` `lg` `sh` | 상의·하의·신발 | 그대로 (옷 입은 고양이) |
| `ha` | 모자 | 그대로 |

`Figure.Parts` 문자열을 유지하면 저장된 데이터가 그대로 살아남는다. **마이그레이션 불필요.**

### 세계관·이름
| 지금 | 바꿔서 |
|---|---|
| 선실(`cabin_default_01`) | 항구 마을의 **내 집 다락방** |
| 메인 갑판(`deck_main`) | **부둣가 광장** |
| 댄스홀 | 그대로 (부둣가 창고를 개조한 홀) |
| 콜라 자판기 · 콜라 캔 | **우유 자판기 · 우유팩** |
| 루피 | 그대로 두거나 **비늘/조개** 같은 것으로 |
| 팝플 | 새 이름 (고양이+항구 계열) |

### 로드맵에 생기는 변화
- **낚시**가 중심 콘텐츠가 된다. 부둣가에서 낚시 → 생선 → 팔거나 먹거나 장식.
- **펫**은 재검토. 고양이가 주인공인데 펫이 또 고양이면 어색하다 → 새·물고기·화분으로.
- 꽃 화분은 그대로 (창가에서 키우는 그림이 오히려 더 맞는다).

## 비용
| 항목 | 규모 |
|---|---|
| `AvatarView._Draw` 다시 그리기 | 코드 ~150줄 |
| `Ui` 색 팔레트(FurColors, 무늬색) | 작음 |
| `HudView` 외모 창 라벨 (털색/무늬) | 작음 |
| 방·가구 JSON 이름·문구 | 작음, 기계적 |
| 저장 데이터 | **변경 없음** (figure 형식 유지) |

## 권고
아바타부터 바꾼다. 가장 눈에 띄고 가장 싸다. 세계관 이름은 그 뒤에 한 번에 정리한다.
